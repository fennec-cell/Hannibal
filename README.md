# HANNIBAL — This is my design

[![Deploy static site](https://github.com/fennec-cell/Hannibal/actions/workflows/deploy.yml/badge.svg)](https://github.com/fennec-cell/Hannibal/actions/workflows/deploy.yml)

Фан-портал по сериалу «Ганнибал» (2013–2015): персонажи, сюжет, символика, кухня, интерактивные игры и плейлист. Сайт статический (HTML, CSS, JavaScript) и обновляется автоматически при каждом изменении в репозитории.

## Ссылки

- Сайт на GitHub Pages: https://fennec-cell.github.io/Hannibal/
- Сайт на Vercel: https://ВАША-ССЫЛКА.vercel.app
- Статус сборки: бейдж выше показывает результат последнего запуска workflow

## Разделы сайта

- **Главная** — визуальный архив с галереей кадров
- **Персонажи** — 3D-карточки героев и подробные психологические досье
- **Сюжет** — три сезона с аккордеоном по сериям и фотогалереей
- **Символика** — мифологические, религиозные и литературные отсылки сериала
- **Высокая кухня** — 16 рецептов блюд из сериала и генератор ужина
- **Игра Уилла** — интерактивное расследование с допросом, уликами и маятником
- **Плейлист** — виниловый плеер с саундтреком и классикой
- **Психо-тест** — 12 вопросов, определяющих ваш персонаж
- **Поиск** — быстрый поиск по всему порталу (кнопка «Поиск» или Ctrl+K)

## Технологии

- HTML5, CSS3, JavaScript (без фреймворков)
- Tailwind CSS (CDN)
- Шрифты Google Fonts: Cinzel Decorative, Cormorant Garamond
- GitHub Actions для автоматического деплоя
- GitHub Pages и Vercel для хостинга

## Как устроен автодеплой (CI/CD)

1. Разработчик вносит изменения в файлы и делает push в ветку `main`.
2. GitHub Actions запускает workflow `.github/workflows/deploy.yml`.
3. Workflow упаковывает файлы сайта в артефакт и публикует его на GitHub Pages.
4. Параллельно Vercel (через встроенную интеграцию с GitHub) собирает и публикует ту же версию сайта.
5. Статус последнего запуска виден по бейджу в начале этого файла.

Ручная загрузка файлов на хостинг не требуется.

## Структура репозитория

- `index.html` — главная страница и весь интерфейс
- `search-main.js` — скрипт поиска (если используется отдельным файлом)
- `.github/workflows/deploy.yml` — сценарий автодеплоя
- изображения и аудио — материалы для разделов сайта

## Запуск на своём компьютере

Скачайте репозиторий и откройте файл `index.html` в браузере. Сервер не нужен.
